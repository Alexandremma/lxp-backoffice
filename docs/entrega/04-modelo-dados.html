B42 LXP — Modelo de dados

Referência stand-alone das tabelas e integrações usadas pelo backoffice e pelo portal do aluno. Abrir offline no navegador.

Schema · admin.*

Cadastro acadêmico, equipe (`backoffice_team_members` — papéis **admin / coordenador / professor**; RLS granular), certificados (templates + biblioteca N:M + snapshot imutável; layout custom), gamificação, cursos (`free_course`) e **configurações** (`lxp_institution_settings`, `lxp_institution_smtp_secret`, `lxp_audit_logs`). UI: `/admin/gamificacao`, `/admin/certificados`, `/admin/configuracoes`, `/admin/perfil`. **RLS writes:** SELECT staff via `is_admin()`; INSERT/UPDATE/DELETE por helpers de matriz (`can_edit_courses`, `can_manage`, `can_write_gamification`, `is_admin_role`). `lxp_award_xp_if_active` / `lxp_evaluate_student_badges` sem EXECUTE para client (só triggers DEFINER); `lxp_reevaluate_all_student_badges` só `authenticated` + check admin. RPCs UI: `lxp_reevaluate_all_student_badges`, `lxp_get_default_certificate_template_id()`, `lxp_write_audit_log`, `lxp_get_settings_dashboard()`, `lxp_get_profile_display()`. **25 tabelas** · migrations até + seeds homolog.

Schema · student.*

Perfil (self-service + avatar), matrículas (`free_course` auto-matrícula), progresso, **horas estudadas** (`lxp_student_study_time` + RPC `lxp_increment_study_seconds`), gamificação (XP, nível, streak de **login**, badges), discussão e anotações na aula, certificados no portfólio. Conteúdo via **Alice**; validação pública `lxp_validate_certificate_public(code)`. Autores de comentários: RPC `lxp_get_profile_display`. **RLS staff:** progresso / XP / badges / daily_access / notes — SELECT staff; WRITE `can_manage` (admin+coord). Equipe modera comentários.
