# 08 — Portfólio, progresso e capas

## Objetivo

Smoke visual e funcional de `/progress`, `/portfolio` e capas nas listagens.

## Papéis

Aluno com algum progresso (ideal) e, se possível, disciplina com capa cadastrada

## Passos

| # | Ação | Resultado esperado | Pass/Fail |
|---|------|--------------------|-----------|
| 1 | Abrir `/progress` | XP, nível, streak; horas estudadas se houver heartbeat | |
| 2 | Cards / trilhas no progresso | Capas aparecem quando cadastradas; sem imagem quebrada | |
| 3 | Dashboard / catálogo com capas | Mesma coerência visual | |
| 4 | Portfólio — badges | Lista ou empty state claro | |
| 5 | Portfólio — certificados | Download quando existir; sem “compartilhar” se fora de escopo | |
| 6 | Permanecer alguns minutos em uma aula | Horas/minutos de estudo tendem a subir após heartbeat | |

## Aceite

Telas carregam sem erro; métricas honestas com a regra oficial (ver ficha técnica).
