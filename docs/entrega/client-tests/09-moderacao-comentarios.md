# 09 — Moderação de comentários

## Objetivo

Equipe modera discussão no **portal alunos**; aluno continua com XP e regras normais.

## Papéis

Professor ou coordenador (ou admin) + Aluno

## Passos — Equipe no portal alunos

| # | Ação | Resultado esperado | Pass/Fail |
|---|------|--------------------|-----------|
| 1 | Login equipe no app alunos | Entra em modo moderação (banner / catálogo sem auto-matrícula típica de aluno) | |
| 2 | Abrir disciplina/aula | Discussão disponível; sem fluxo de “concluir aula” de aluno | |
| 3 | Comentar como equipe | Badge de equipe; sem ganhar XP de aluno | |
| 4 | Excluir comentário de aluno | Some da thread; auditoria no backoffice registra ação | |

## Passos — Aluno

| # | Ação | Resultado esperado | Pass/Fail |
|---|------|--------------------|-----------|
| 5 | Ver comentário da equipe | Badge visível; não consegue excluir alheio | |
| 6 | Comentar | Recebe XP conforme regra | |

## Aceite

Moderação só para equipe; aluno não eleva privilégio.
